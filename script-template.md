# Script template (15-25s)
1. HOOK (0-2s, on-screen text + voice): the promise
2. ITEMS (3 x ~5s): product clip + price + one reason
3. CTA (last 3s): "Link in bio" / "Follow for more gifts"

## Hook formulas
- "Gifts under $[X] that look expensive"
- "Stop buying [person] [boring thing] - get this"
- "[N] gifts nobody expects under $[X]"
- "Don't buy [X] before you see this"
- "Last-minute gifts that still arrive before Christmas"

## Checklist before posting
- Hook in first second, captions on, no copyrighted music outside TikTok's library
- Price accurate today, affiliate disclosure in caption
- 3-5 hashtags: #giftideas #christmasgifts #giftsunder25 + niche tag
