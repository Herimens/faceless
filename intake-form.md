# Custom plan intake form (send via WhatsApp/Google Form)
- Name, WhatsApp, country/city
- Plot size (m x m) + shape; plot photo or sketch; location (urban/rural/hill/etc.)
- Building type: house / villa / rental block / camp-lodge / other
- Bedrooms, bathrooms, living/dining/kitchen, garage, extras
- Floors (single/double), roof style, style references (photos)
- Budget range and target build start
- Must-haves / dislikes
- Deadline
- Is a permit-ready set needed? (needs registered architect partner)
